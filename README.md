# 세페이드 변광성으로 은하까지 거리 재기 — 체험 사이트

세페이드 변광성을 찾아 → 촬영 → 구경측광·차등측광 → 시계열분석(주기) → 주기-광도 관계 → 포그슨 방정식으로 **은하까지의 거리**를 구하는 과정을 브라우저에서 직접 체험합니다. (고교~대학 입문, 한국어)

## 실행
`index.html` 을 더블클릭하면 됩니다. 빌드·설치·인터넷 연결이 필요 없습니다.
(진행 상황은 브라우저 localStorage 에 저장되고, 상단의 "처음부터"로 초기화할 수 있습니다.)

## 체험 흐름
| 단계 | 하는 일 |
|---|---|
| 1. 변광성 찾기 | 룰렛으로 은하(M31 / M33 / NGC 300 / NGC 2403) 중 하나를 랜덤으로 뽑고, 은하 그림(대략적인 모습의 일러스트) 위에 하이라이트된 변광성을 관측 대상으로 선택 (은하 이름은 룰렛에서 공개, 은하까지의 거리는 마지막까지 비공개) |
| 2. 촬영 | 약 90일 동안 날짜가 흘러가며 사진이 쌓이는 연출 (구름·망원경 시간 부족으로 불규칙한 간격) |
| 3. 측광 | 구경측광은 자동, 학생은 **비교성**을 직접 골라 차등측광. 비교성 점검(포화·가장자리·혼입·변광) 피드백 |
| 4. 주기 찾기 | Lomb–Scargle 주기도 → 위상 접기 → 푸리에 적합, 세페이드 / 식쌍성 분류 |
| 5. 주기-광도 관계 | 같은 은하의 m–log P 직선 + 은하수 보정 세페이드(교육용 가상 세트)로 영점 → 절대등급·광도 |
| 6. 거리 계산 | 포그슨 방정식 `m − M = 5 log10(d/10pc)` (성간소광 보정 선택) → 정답 공개·성적표 |

## 도전 과제 (+난이도)
새로운 걸 시키는 게 아니라, 컴퓨터가 자동으로 해 준 계산을 학생이 직접 해 보고 스스로 채점하는 선택 과제예요. 건너뛰어도 다음 단계로 갈 수 있어요.

| 단계 | 도전 과제 |
|---|---|
| 2 | 없음 |
| 3 | 구경측광 직접 정해 보기: 구경 반지름과 하늘 고리를 직접 정하면 크기, S/N, 고리 위치·넓이, 이웃 별 걸림을 점검해 줘요. (자동 설정도 그대로 있어요) |
| 4 | 위상 직접 계산, 곡선을 읽어 진폭·평균 등급 구하기, 비대칭을 계산해 세페이드/식쌍성 판정하기 |
| 5 | 시차 → 거리 → 절대등급 계산, 최소제곱 직선의 기울기 손계산, 주기 → 절대등급 → 광도 계산 |
| 6 | 별 하나의 μ와 거리, 평균·표준편차·표준오차, 최종 거리와 오차, 먼지 보정(A_V) 계산 |

## 구조
- `js/core/` — 시뮬레이터(`sim.js`), 측광(`photometry.js`), 시계열(`timeseries.js`), PL·포그슨(`plfit.js`), 이를 잇는 `pipeline.js`
- `js/ui/` — 단계별 화면(`step1~6.js`), 차트(`charts.js`), DOM 도우미(`util.js`)
- `js/app.js` — 상태·내비게이션·용어집
- 모든 이미지는 시드 고정 난수로 브라우저에서 합성합니다 (같은 시드면 같은 하늘).

## 테스트
```bash
node tests/test_core.js
```
주기 복원, 포그슨 왕복, 회귀, 그리고 4개 은하 전체 파이프라인(측광→주기→PL→거리, 소광 보정 후 ±12% 이내)을 검사합니다.

## 교육용 단순화 (사실과 다른 점)
- 은하 거리 모듈러스, 소광 A_V, 주기-광도 관계 계수(M_V = −2.43 (log P − 1) − 4.05)는 문헌 값을 단순화한 근사입니다.
- 은하수 보정 세페이드는 위 관계식에 산포를 더해 만든 **가상 세트**입니다.
- 망원경·카메라는 가상의 장비이며, 사진은 변광성 주변의 작은 시야만 담습니다. 금속량 효과 등은 다루지 않습니다.
