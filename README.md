# 세페이드 거리 측정 Lab

**변광성의 주기로 은하까지의 거리를 재는 실험실**

세페이드 변광성을 찾고, 석 달 동안 사진을 찍고, 밝기를 재서 주기를 구한 뒤, 주기-광도 관계와 포그슨 방정식으로 **은하까지의 거리**를 직접 계산해 보는 한국어 교육용 웹사이트입니다. 고등학교 3학년 ~ 대학 1학년 수준에 맞췄습니다.

- 사이트: https://h00ns0lar.github.io/cepheid_education/
- 빌드·설치·인터넷 연결 없이 `index.html`을 더블클릭해도 그대로 돌아갑니다.
- 진행 상황은 브라우저(localStorage)에 저장되고, 왼쪽 아래 **처음부터**로 초기화할 수 있습니다.

## 체험 흐름

| 단계 | 하는 일 |
|---|---|
| 1. 변광성 찾기 | 버튼 한 번으로 은하 하나를 무작위로 뽑고, 은하 그림 위에서 깜빡이는 변광성을 관측 대상으로 고릅니다. 이 은하까지 몇 광년쯤일지 먼저 감으로 예상해 둡니다. (은하 이름은 바로 공개, 거리는 마지막까지 비밀) |
| 2. 촬영 | 약 90일 동안 날짜가 흐르며 사진이 쌓입니다. 구름 낀 밤, 망원경을 못 쓰는 밤이 섞여 촬영 간격이 불규칙합니다. 촬영하는 동안 돔 안의 망원경이 별을 따라 움직입니다. |
| 3. 밝기 재기 | 구경측광(별 둘레 원 안의 빛 합치기 − 배경 고리로 배경빛 빼기)은 자동이고, 학생은 V1의 **비교성**을 직접 골라 차등측광을 합니다. 포화·가장자리·이웃 별 섞임·변광 여부를 점검해 줍니다. 구경과 배경 고리를 직접 정해 보는 연습(+난이도)도 있습니다. |
| 4. 주기 찾기 | 광도곡선에서 먼저 "몇 번 밝아졌나"를 세어 주기를 어림한 뒤, Lomb–Scargle 주기도 → 위상 중첩 → 푸리에 적합으로 주기를 다듬고, 곡선 모양으로 세페이드와 식쌍성을 가려냅니다. |
| 5. 주기-광도 관계 | 4단계에서 구한 주기를 문헌의 식 M_V = −2.43 (log P − 1) − 4.05 에 별마다 직접 대입해 절대등급 M과 광도(태양의 몇 배)를 구합니다. |
| 6. 거리 계산 | 포그슨 방정식 m − M = 5 log(d / 10 pc) 로 별마다 거리를 구하고 평균을 냅니다. 먼지 보정(성간소광 A_V)을 선택한 뒤 실제 거리를 공개하고, 별점이나 등급과 결과 코드를 보여 줍니다. |

거리는 모두 **광년을 먼저, 파섹은 괄호 안에** 적습니다. 예: 256만 광년 (783.4 kpc)

## 은하 4개

| 은하 | 종류 | 실제 거리 | 그림에 담은 특징 |
|---|---|---|---|
| 안드로메다 은하 (M31) | 나선은하 | 약 256만 광년 | 비스듬히 누운 원반, 넓고 노르스름한 안쪽, 짙은 먼지띠, 위성 은하 M32·M110 |
| 삼각형자리 은하 (M33) | 나선은하 | 약 274만 광년 | 조각조각 흩어진 푸른 팔, 분홍 수소 구름이 많음, 큰 수소 구름 NGC 604 |
| 조각가자리 NGC 300 | 나선은하 | 약 621만 광년 | 넓게 퍼진 보랏빛 원반, 분홍빛 중심부를 두른 먼지 고리, 앞쪽 별의 십자 빛줄기 |
| 대마젤란 은하 (LMC) | 막대가 있는 불규칙은하 | 약 16만 광년 | 크림색 막대, 위쪽의 활 모양 푸른 별 생성 지역, 분홍빛 타란툴라 성운 |

은하 그림은 실제 사진을 참고해 브라우저에서 직접 그린 일러스트입니다. 사진을 그대로 쓰지 않아서 저작권 걱정이 없고, 변광성이 놓이는 자리도 그림의 팔·막대와 정확히 맞습니다.

## 직접 풀어 보는 장치

- **먼저 예측하고 확인하기**: 컴퓨터가 답을 보여 주기 전에 먼저 어림합니다.
  - 1단계: 은하까지의 거리
  - 4단계: V1의 주기 (그래프만 보고)
  - 5단계: 가장 밝은 별
  - 6단계: 먼지 보정을 하면 거리가 멀어질지 가까워질지
- **첫 별(V1)은 직접**: 4·5·6단계 모두 V1을 학생이 직접 풀어야 "나머지 자동" 버튼이 열립니다.
  - 4단계: V1의 주기와 종류를 직접 정합니다. 막히면 힌트를 하나씩 열 수 있습니다.
  - 나머지 별도 "주기 어림해 보기" 칸으로 직접 어림할 수 있습니다.
  - 5·6단계: 앞 단계에서 구한 값이 표로 나오고, 식에 값을 대입해 빈칸을 채운 뒤 스스로 채점합니다.
- **자동 계산은 맨 아래 작은 버튼**: 미리 풀려 있는 값은 없습니다. 자동 버튼은 언제든 쓸 수 있지만, 많이 쓰면 별점 대신 "보조 관측원" 등급을 받습니다 (아래 등급 참고).
- **내 기록**: 정답 공개 화면에 다음이 정리됩니다.
  - 처음 예상 → 내가 잰 거리 → 실제 거리
  - 예측을 맞혔는지
  - 직접 한 것과 컴퓨터에게 맡긴 것
  - 힌트를 쓴 횟수

## 결과 등급

정답을 **처음 확인하는 순간**의 결과로 등급을 매기고 고정합니다. 정답을 본 뒤에 먼지 보정을 바꾸거나 별을 빼도 등급은 그대로입니다.

**두 갈래**
- 별마다 직접 할 수 있는 일(4단계 주기·분류, 5단계 절대등급, 6단계 거리) 가운데 **절반 넘게 직접** 풀면 ★1~5 별점을 받습니다.
- 절반 넘게 자동 계산이나 "풀이 보고 넘어가기"로 넘기면 별점 대신 **보조 관측원** 등급을 받고, 다음에 직접 풀어 보라는 안내가 나옵니다.

**별점 계산 (100점)**

| 항목 | 배점 | 기준 |
|---|---|---|
| 거리 정확도 | 30 | 실제 거리와의 오차: 5% 안 30점, 10% 안 22점, 20% 안 12점, 그 밖 5점 |
| 직접 풀이 | 30 | 직접 푼 비율 × 30 |
| 예측 | 15 | 처음 거리 예상(2배 안), V1 주기 어림(15% 안), 가장 밝은 별, 먼지 보정 방향 (각 3.75점, 거리·주기는 조금 빗나가면 절반) |
| 활동 시간 | 15 | 20~60분 만점, 12~20분·60~90분 10점, 그 밖 5점, 2시간 넘으면 3점 |
| 힌트·풀이 보기 | −10까지 | 4단계 힌트를 하나 열 때마다, 그리고 "정답과 풀이 보기"를 열었거나 풀이 보고 넘어간 별 하나마다 −2점 |

90점 이상 ★5, 75점 ★4, 60점 ★3, 45점 ★2, 그 아래 ★1.

**활동 시간**은 1단계에서 은하를 뽑은 순간부터 정답을 확인할 때까지, 실제로 화면을 쓴 시간만 잽니다. 탭을 떠나 있거나 2분 넘게 아무것도 안 한 시간은 빠집니다.

**몇 번째 도전**인지도 함께 기록합니다. "처음부터"를 눌러도 이 횟수는 지워지지 않습니다.

**결과 코드 (선생님 제출용)**
- 결과 화면에 `M31-S4-E3-T38-N2-K7Q2` 같은 코드가 나옵니다. 차례대로 은하, 별점(S4 = ★4, B = 보조 관측원), 거리 오차 %, 활동 시간(분), 몇 번째 도전, 확인 글자입니다.
- 사이트 주소 뒤에 `?code=결과코드`를 붙여 열면 코드가 진짜인지 확인해 줍니다. 숫자를 고쳐 쓰면 확인 글자가 맞지 않습니다.
  예: `https://h00ns0lar.github.io/cepheid_education/?code=M31-S4-E3-T38-N2-K7Q2`
- 서버가 없어서 결과는 학생 브라우저에만 저장됩니다. 학생이 결과 코드나 화면 캡처를 제출하는 방식으로 모아 주세요.
- 확인 글자는 학생이 숫자를 손으로 고치는 것을 막는 정도의 장치입니다. 코드를 꼼꼼히 뜯어보면 흉내 낼 수 있습니다.

## 심화 탐구 (+난이도)

새로운 문제를 내는 대신, **위에서 컴퓨터가 자동으로 해 준 계산을 학생이 계산기로 직접 해 보고 스스로 채점**하는 선택 과제입니다. 건너뛰어도 다음 단계로 갈 수 있습니다.

| 단계 | 심화 탐구 |
|---|---|
| 2 | 없음 |
| 3 | 구경 반지름과 배경 고리를 직접 정해 보기. 크기, S/N, 고리 위치·넓이, 이웃 별 걸림을 점검해 줍니다. (자동 설정, 자동 설정 원 겹쳐 보기 포함) |
| 4 | 위상 손계산, 위상 중첩 곡선을 읽어 가장 밝을 때·어두울 때·진폭·평균 등급 구하기 |
| 5 | 이 은하의 m–log P 그래프를 그려 문헌 기울기와 비교, 최소제곱 직선의 기울기 손계산, 우리 은하 보정 세페이드(가상) 7개의 시차 → 거리 → 절대등급 |
| 6 | 별마다 구한 μ의 평균·표준편차·표준오차, 최종 거리와 오차 범위, 먼지 보정(A_V) 계산 |

## 교육용 단순화 (실제와 다른 점)

- 은하의 거리 모듈러스, 성간소광 A_V, 주기-광도 관계 계수(M_V = −2.43 (log P − 1) − 4.05)는 문헌 값을 단순하게 다듬은 근사값입니다.
- 심화 탐구의 우리 은하 보정 세페이드(MW-1 ~ MW-7)는 위 관계식에 산포를 더해 만든 **가상의 별**입니다.
- 대마젤란 은하는 아주 가까워 별이 다른 은하보다 수백 배 밝습니다. 그래서 노출을 짧게 찍었다고 보고 카메라 영점만 옮겼습니다. 화면의 비교성·목표 별 등급은 실제 밝기 그대로입니다.
- 망원경과 카메라는 가상의 장비이고, 사진에는 변광성 주변의 좁은 하늘만 담깁니다.
- 금속량에 따른 주기-광도 관계 차이 등은 다루지 않습니다.
